These projects simulate real-world applications and strengthen problem-solving and software development skills.

# 🚀 Getting Started

## Prerequisites

* GCC Compiler / MinGW
* Visual Studio Code
* C++11 or above
* Git

---

## Installation

### Clone Repository

```bash
git clone https://github.com/iampriyanshuraj01-beep/CPP-PROJECTS.git

cd CPP-PROJECTS
```

### Compile

```bash
g++ filename.cpp -o output
```

Example:

```bash
g++ HospitalManagementSystem.cpp -o hospital
```

### Run

```bash
./output
```

Windows:

```bash
output.exe
```
